## Logits of API-Protected LLMs Leak Proprietary Information

_arXiv · 2024-11-08 · score 0.8_

In this work we show that, with only a conservative assumption about the model architecture, it is possible to learn a surprisingly large amount of non-public information about an API-protected LLM from a relatively small number of API queries (e.g., costing under $1000 USD for OpenAI's gpt-3.5-turbo).
